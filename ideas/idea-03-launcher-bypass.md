# Idea: Launcher Bypass for Third-Party Game Launchers

Status: 💡 raw

## Description
When streaming a game via Sunshine, third-party launchers (GOG Galaxy, EA App, CDPR launcher) often open instead of the game directly. Add built-in launcher detection or a bypass mechanism so Sunshine can launch games directly without manual command configuration per game.

## Why it matters for TCC
Improves out-of-the-box experience for a common use case. Sunshine already supports custom launch commands, but there's no automated detection. A launcher registry or heuristic detection would be a user-facing improvement.
